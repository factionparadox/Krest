 Крест — keys                                               (q closes this)

 Super is the Windows key. Super + a key: windows and the session.
 Ctrl + Super + a key: programs (the chords).

 WORKSTATIONS                              PROGRAMS  (Ctrl+Super + ...)
 Super+1 … 9        go to workstation 1-9  w      web (Firefox)
 Super+Shift+1 … 9  send the window there  t      terminal (X-терминал)
 Super+Tab          overview: pick a       d      Discord (WebCord)
                    window or workstation  v      video (VLC if installed, else mpv)
                                           e      files (mc)
 WINDOWS                                   a      ani-cli
 Super+q            close the window       p      Proton VPN (the app)
 Super+f            this window full size  c      acme (write)
                                           o      office (LibreOffice)
                                           y      YouTube (FreeTube)
                                           g      games (Steam)
 Super+r            width 33/50/67/100%    r      Russian menu
 Super+`            next window            n / b / m   Wi-Fi / Bluetooth / sound mixer
 Super+Shift+Tab    previous window        Space  the Krest menu
 Super+\            split side by side
 Super+-            split top and bottom   Super+Space    run any program (dmenu)
 Super+Backspace    remove this frame      Super+Return   terminal
 Super+o            back to one frame
 Super+arrows       move between frames    SESSION
 Super+Shift+arrows swap windows           Super+x        lock
                                           Super+z        suspend (hibernates after 2 h)
 SCREENSHOTS                               Super+Escape   power menu
 Super+Shift+s      an area                Super+?        this sheet
 Print / Shift+Print  whole screen / area  Super+Shift+r  reload the settings

 No floating windows: ratpoison gives every window a frame, so there is nothing to drag.

 CLIPBOARD     Super+v: what you copied lately; pick one and it is on the clipboard again.
 X-ТЕРМИНАЛ    select text = copied · Ctrl+Shift+v paste · Shift+PgUp/PgDn or the wheel: scroll
               back · double-click a word, then right-click it: open it (a file in acme, a URL,
               a man page like ls(1)) · Ctrl+Shift+PgUp/PgDn: bigger / smaller text

 LANGUAGE      Alt+Shift switches English / Russian (phonetic: я on q, в on w, ж on v ...)
 LAPTOP KEYS   volume, mute, microphone and brightness keys work as marked.

 RATPOISON'S OWN KEYS   Ctrl+t, then:
   ?  all keys    c  terminal    n/p  next/previous    k  close    s/S  split    Q  one frame
   :  type a ratpoison command (e.g.  :windows)

 MIDNIGHT COMMANDER (mc)   Tab other panel · F3 view · F4 edit · F5 copy · F6 move
                           F7 new folder · F8 delete · F10 quit · Ctrl+o the shell underneath
 ACME     middle-click runs a word · right-click opens it · Put saves · Del closes ·
          type a file name anywhere and right-click it to open it

 Learn more:  krest-learn browse   (or Ctrl+Super+Space → Learn the system)
